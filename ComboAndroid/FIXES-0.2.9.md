# Combo Ship 0.2.9

- Let OoT's check tracker plan age-changing routes using the active Song of Time enhancement, even when the seed was generated without that logic assumption. Owned songs, instruments, playable buttons and the selected equipment requirements still apply.
- Show checks reachable through a known shuffled entrance without requiring the player to enter that dungeon or switch age first. The search can change age along a reachable route and use the new age's equipment.
- Refresh availability when the age-change option is enabled, disabled or changed. No area transition or save reload is needed.
- Keep the seed generator's separately selected logic rules unchanged. Individual entrance, equipment, song and key requirements still decide which checks are available.

Existing seeds and saves are preserved. Install over the previous version.
