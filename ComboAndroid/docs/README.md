# Combo Ship Android docs

- [CHANGELOG.md](CHANGELOG.md): one short section per build, newest first (0.3.9 down to 0.1.0), with the date, the main changes and how each build was tested. Start here.
- [ROADMAP.md](ROADMAP.md): the remaining authorized work, in build order, and what is not authorized.
- [history/](history/): the detailed notes written during development (September 25 to October 8, 2026). They describe each release as it was at the time; later releases supersede them. Only relative links were updated when they moved here.

The build guide ([BUILDING.md](../BUILDING.md)), the phone test checklist ([DEVICE_TESTS.md](../DEVICE_TESTS.md)) and the port [README](../README.md) stay in the `ComboAndroid/` folder.

## What is in history/

| Files | Contents |
| --- | --- |
| `FIXES-<version>.md` | Changes and suggested phone checks for each release, 0.1.2 to 0.2.19. |
| `VALIDATION.md` | Combined build and test log for 0.1.1 and 0.1.10 to 0.1.20. |
| `VALIDATION-<version>.md` | Test evidence and stated limits for each release, 0.1.21 to 0.2.19. |
| `RELEASE-AUDIT-<version>.md` | Request-by-request completion audits for 0.2.0 to 0.2.3. |
| `NEXT-PATCH-BACKLOG.md` | The requested-work list and its status per release, last updated October 8, 2026. |
| `OOTMM-LOGIC-AUDIT.md`, `ENHANCEMENT-LOGIC-AUDIT-0.1.21.md`, `LOGIC-0121-VALIDATION.md`, `LOGIC-AUDIT-0.1.23.md` | Logic audits against OoTMM for the 0.1.19 to 0.1.23 work. |
| `LOGIC-COMPARISON-2026-10-04.md` | Dated comparison of all settings and logic with the OoTMM website. Its data files are in [../logic-comparison-2026-10-04/](../logic-comparison-2026-10-04/). |
| `SUPPORTED-LOGIC-0.2.12.md`, `RESOURCE-PARITY-0.2.13.md`, `LOGIC-PARITY-0.2.14.md` | Rule-by-rule mapping to OoTMM v32.3 for the 0.2.12 to 0.2.14 logic corrections. |
| `MM-TRICKS-0123-REFERENCE.md` | The ten optional MM techniques and what each requires. |
| `UNIFORM-EDITORS-0.1.21.md` | Sliders, the shared HUD editor and the techniques catalogue as introduced in 0.1.21. |

Notes for the 0.2.20 test builds and for 0.3.0 to 0.3.9 were delivered next to the APKs and are not in this repository. CHANGELOG.md summarizes them.
