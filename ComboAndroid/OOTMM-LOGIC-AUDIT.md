# OoTMM reference comparison — updated October 2, 2026

Historical 0.1.21 comparison. Coverage below describes that release; 0.1.23 adds ageless Soaring, twenty ordinary interior age routes, egg-count/daytime-Skulltula rules, Early Frog and eight MM techniques. See the current [0.1.23 audit](LOGIC-AUDIT-0.1.23.md) and [technique reference](MM-TRICKS-0123-REFERENCE.md) for the superseding requirements and validation limits.

Reference: [OoTMM](https://ootmm.com/), [Warp Songs wiki](https://ootmm.wiki.gg/wiki/Warp_Songs), and pinned source commit [`a284b8aab4c707ceb35278fbc66a2271002a20f0`](https://github.com/OoTMM/OoTMM/tree/a284b8aab4c707ceb35278fbc66a2271002a20f0). The local research checkout matched upstream HEAD when the September 30 research was performed; that is not a current-HEAD claim. The wiki's indexed summary was readable; a direct fetch returned HTTP 403. Implementation details below were checked against the pinned source and native engines, not inferred from the wiki summary.

This is a targeted comparison of the current patch's settings and song travel, not a claim that every check in both engines matches OoTMM.

The generator exchanges reachable song destinations between the two engines until no further routes open, before collecting another sphere's items. Each probe starts with empty arrival masks and fresh song knowledge from both inventories. The exact mapping and original runtime/logic choices are serialized with the seed; intentional run overrides are stored separately and included in multiplayer identity. Deterministic legacy migration uses that slot's original data rather than the previously loaded slot's live values. Generating a candidate does not replace the current run's routes.

Mixed destinations are non-monotone. Randomizer creates the shuffled map only when destination shuffling is included in logic. An enhancement-only selection reuses the seed's recorded map; a seed generated without shuffled destinations retains identity destinations. Playing foreign songs without requiring them in generation remains an optional extra ability.

The user's Spirit Temple example is **foreign Requiem playback**, not Soaring randomly leading to Colossus: learned Requiem and the currently played game's instrument/buttons are required. That case has a dedicated regression test, including removal of the song, local instrument, required local button, and access to MM. Destination shuffle is an additional independent option, off by default.

Known differences remain: foreign-song knowledge sharing rather than separate foreign-song item pools, no optional ageless Soaring, conservative age/form traversal, only two verified MM techniques, and no required shortcuts from unaudited movement/glitch cheats. Native No Trade still requires the Gibdo Mask, while OoTMM's open-well setting is broader. Unlimited Deku hopping covers verified low-beach surface returns, not ascent to the marine laboratory's platform. These limits are deliberate prerequisites/coverage distinctions, not claims that the port reproduces every OoTMM route.

See [the enhancement coverage audit](ENHANCEMENT-LOGIC-AUDIT-0.1.21.md), [combined logic verification notes](LOGIC-0121-VALIDATION.md) and [release validation](VALIDATION-0.1.21.md) for implementation and test evidence. Host models, native-engine generation, emulator gameplay and physical-phone testing are distinct evidence levels. Warning-only mid-run changes remain allowed and do not modify the original seed's settings or placements.
