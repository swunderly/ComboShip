# Combo Ship Android 0.1.23

This update finishes the remaining supported logic and settings additions from the accepted patch list. Install it over the existing Combo Ship app; the application ID and signing certificate are unchanged.

- **Adult Soaring:** a shared Song of Soaring at any age option, with its own optional logic assumption. Cross-game songs, ownership, local instrument/buttons and owl unlocks remain required.
- **Quest and time rules:** the chosen Zora egg count now affects Bossa Nova logic; verified daytime Skulltula spawns now have a matching logic option.
- **Age travel:** Song of Time logic now includes audited ordinary houses, shops, the laboratory and Lon Lon Ranch.
- **Early Eyeball Frog:** its existing restoration has a separate normal Tricks & glitches selection. Restoration-only activation does not affect logic.
- **MM techniques:** eight additional optional routes/minigames share the same searchable catalogue and saved settings as OoT techniques.
- **Menu discovery:** shared screen/HUD, tracker, multiplayer and gameplay controls have explicit search aliases. Both games' technique names are searchable globally and open the matching catalogue entry. Rule search leads to the shared Randomizer and Enhancements pages. About displays the APK's actual version.
- **Generator initialization:** saved arrow rules can be applied safely during standalone native generation, before gameplay hooks exist.

Earlier releases already delivered the one-chick Bremen alternative, native cross-game song presentation, combined reachability guarantees, unified tracker knowledge/path hints, automatic fitting and HUD positioning, numeric sliders, faded OoT save-editor icons, named MM owl editing and the five-trip Shadow Door restoration. Those features remain included.

Fierce Deity gap jumping remains outside logic as requested. General movement cheats and unaudited glitch routes remain enhancement-only; this update does not claim every OoTMM ROM technique or foreign-equipment feature.

## Phone checks

1. Search for **Soaring**, **Zora eggs**, **Night Skulltulas**, **Early Eyeball Frog**, **Pinnacle**, **HUD layout** and **icon spacing**; verify the results lead to the shared page.
2. In Enhancements → Gameplay rules, try Adult Soaring with cross-game songs enabled. Verify native performance, zero-owl message, selection and cancellation. Save/restart and confirm your choices persist.
3. Change the egg count in Randomizer → Gameplay rules and confirm the matching enhancement updates. An enhancement-only change should leave its logic checkbox off.
4. Open Randomizer → Tricks & glitches, select MM and inspect the new optional techniques. Leave difficult techniques off unless you want the seed to require them.
5. Check both save editors, tracker shortcut/docking, screen fit and audio during normal play. Confirm About shows 0.1.23.
